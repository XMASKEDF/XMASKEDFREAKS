# Environment Variable Master List

Source: `.env.example` and repository `process.env` references. Values are intentionally omitted.

## Core / Public

`NODE_ENV`, `APP_ENV`, `APP_URL`, `NEXT_PUBLIC_SITE_URL`, `NEXT_DIST_DIR`, `XMF_ENVIRONMENT`, `XMF_SANDBOX_MODE`, `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `NEXT_PUBLIC_TURNSTILE_SITE_KEY`.

`NEXT_PUBLIC_*` values are browser-visible. Supabase service access is server-only.

## Database / Auth

`SUPABASE_SERVICE_ROLE_KEY`, `ADMIN_SETUP_SECRET`, `ADMIN_DEVICE_SALT`, `ADMIN_REAUTH_MAX_MINUTES`, `ADMIN_DEV_AUTH_ENABLED`, `ADMIN_DEV_EMAIL`, `ADMIN_DEV_EMAIL_2FA`, `ADMIN_DEV_PASSWORD_HASH`, `ADMIN_DEV_SESSION_SECRET`, `ADMIN_DEV_USERNAME`, `POLICY_ACCEPTANCE_SALT`, `CONTRIBUTION_IDENTITY_SALT`.

## Payments / Commerce

`PAYMENT_PROVIDER`, `PAYMENT_DISABLED_CUSTOMER_MODE`, `PAYMENT_TEST_SECRET`, `SEGPAY_MERCHANT_ID`, `SEGPAY_PRODUCT_CODE`, `SEGPAY_HOSTED_CHECKOUT_URL`, `SEGPAY_POSTBACK_SECRET`, `SEGPAY_RETURN_URL`, `CCBILL_ACCOUNT_NUMBER`, `CCBILL_SUBACCOUNT_NUMBER`, `CCBILL_FLEXFORM_ID`, `CCBILL_API_BASE_URL`, `CCBILL_WEBHOOK_SECRET`, `CCBILL_RETURN_URL`, `TAX_API_URL`, `TAX_API_KEY`, `DEPOSIT_ALERT_EMAIL`.

All payment secrets are server-only. Real settlement is disabled until an approved provider is configured.

## Email / AI / Analytics

`EMAIL_API_URL`, `EMAIL_API_KEY`, `EMAIL_FROM`, `ADMIN_SUPPORT_EMAIL`, `SUPPORT_ESCALATION_ENDPOINT`, `OPENAI_API_KEY`, `OPENAI_SUPPORT_MODEL`, `ANTHROPIC_API_KEY`, `CLAUDE_API_KEY`, `CLAUDE_CONTROL_MODEL`, `ANALYTICS_HASH_SALT`, `ANALYTICS_RETENTION_DAYS`, `ERROR_MONITOR_DSN`.

## Printify / rollout

`PRINTIFY_INTEGRATION_MODE`, `PRINTIFY_API_TOKEN`, `PRINTIFY_API_KEY`, `PRINTIFY_SHOP_ID`, `PRINTIFY_WEBHOOK_SECRET`, `XMF_FLAG_NEW_CHECKOUT`, `XMF_FLAG_NEW_STREAM_PLAYER`, `XMF_FLAG_NEW_GAME_ENGINE`, `XMF_FLAG_NEW_STORAGE`, `XMF_FLAG_NEW_PAYMENT_PROVIDER`, `WATCHPACK_POLLING`, `VERCEL_GIT_COMMIT_SHA`.
